# 菜单数据维护

`20261102_retired_menus.mysql.sql` 清理已退出系统的开发管理、上游帮助、文档、地区和消息菜单子树，以及关联的权限接口、角色授权和套餐授权。只删除不再被保留权限引用的关联视图及旧接口命名空间，不删除用户、角色、套餐或业务数据。

此目录不进入发布 manifest，不随应用启动执行，也不适用 SQLite。已有 MySQL 库需先确认目标、备份并显式执行。当前 Development 的自动结构及种子同步仍保持关闭。

执行脚本会保留六张 `hwjy_20261102_*` 原始行备份表，允许重复清理。需要恢复时，在这些记录尚未发生后续修改前执行配套 rollback；遇到任何错误，调用方必须执行 `ROLLBACK`。恢复采用普通 INSERT，主键冲突会中止，不覆盖新记录。确认验收与恢复窗口结束后，由维护人员处置备份表。

新数据库使用已清理的 `InitData/Admin` 种子，不需要执行此维护脚本。不要修改已登记的历史 MySQL baseline 或 checksum。
